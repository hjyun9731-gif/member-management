미수금 월별 성과 대시보드 V5 - 가독성 재설계

핵심 변경
- 한 화면에 모든 그래프/표를 동시에 표시하지 않음
- 핵심 요약 / 월별 추이 / 월별 성과표 / 회원별 조회 4개 보기로 분리
- 기본 화면은 핵심 요약
- 선택한 두 월의 미수금 증감 결과를 대형 문장으로 표시
- KPI 숫자와 글자 크기 확대
- 월별 추이는 별도 화면에서 큰 그래프로 표시
- 성과표는 별도 화면에서 글자/행 높이 확대
- 회원별 조회를 눌렀을 때만 기존 회원목록+상세 패널 표시
- 기존 API/DB 구조, 수납/부과/연락/회원 상세 기능은 유지
