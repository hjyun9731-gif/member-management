폐업현황 + 양도양수대장 가입/미가입 판정 긴급 수정 (2026-08-31)

이전 패치 오류:
- 가입일자 칸에 글자가 하나라도 있으면 가입으로 잡는 fallback이 있었음.
- 실제 원본에는 x / 개별에 등록 / 개별에서 대폐차 / 가입희망 등 비가입 메모가 가입일자 칸에 존재함.

수정 기준:
- 실제 날짜 또는 O/o/ㅇ/○만 '가입'
- 빈칸, x/X, 개별에 등록, 개별에서 대폐차, 대폐차&등록, 가입희망 및 그 밖의 비날짜 텍스트는 '미가입'
- 연결되지 않은 양도자는 임의판정하지 않고 '미확인'
- 공통 판정 함수 app.excel_utils.is_association_member()를 읽기 전용 표시 로직에서 사용
