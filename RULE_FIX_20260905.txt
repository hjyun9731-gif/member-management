2026-09-05 자격증명번호/인가판정 규칙 보정

1) 자격증명발급번호 동일번호 처리
- 26-085 = 26-85 로 동일 번호 취급
- 2026-0085, 다른 하이픈/공백 표기도 같은 번호로 정규화
- 발급이력 검색/중복검사/사용중 연결/취소/재활성/수정에서 year+number 기준으로 동일번호 판정
- 발급이력 관리 화면은 같은 번호가 0 유무로 중복돼 있어도 한 줄로 묶어 표시
- 기존 DB 행 삭제/병합은 하지 않음

2) 인가허가 완료 판정
- 예정자(신규회원 흐름)와 실제 개인회원/택배회원이 연결돼 있으면 인가완료
- 과거 데이터처럼 candidate_id/member_id가 빠져 있어도 같은 성명+차량번호가 개인/택배회원에 있으면 인가완료로 표시
- approval_date가 있으면 기존처럼 인가완료
- 회원/예정자 원본 데이터 삭제/덮어쓰기 없음
