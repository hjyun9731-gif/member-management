변경사항
1. 폐업관리 목록의 "처리정보" 컬럼 삭제
2. 목록은 다음만 표시
   - 관리번호
   - 구분 (폐업 / 양도 / 이관)
   - 회원
   - 지역
   - 차량번호
   - 핸드폰 + U+ 문자
   - 처리일
   - 잔액
3. 양수인 / 이관·양도지역 / 접수일 / 사유 등은 행 클릭 후 오른쪽 상세정보에서 확인
4. 관리번호와 구분은 둘 다 유지
   - 관리번호: 건 식별용
   - 구분: 폐업/양도/이관을 즉시 구분하는 상태값
5. 처리정보 제거로 확보한 폭을 핸드폰/차량번호/지역에 재배분
6. 기존 API/DB/수납/문자/회원업무 로직은 변경하지 않음
