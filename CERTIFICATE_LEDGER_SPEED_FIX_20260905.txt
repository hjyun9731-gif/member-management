자격증명 발급대장 속도 개선

변경 내용
1. GET /api/certificate-ledger 조회 시 전체 예정자 대조를 실행하지 않음
2. GET /api/certificate-ledger/stats 조회 시 전체 대조/번호원장 정리를 실행하지 않음
3. 예정자 저장/수정 시 기존 즉시 연동 로직은 그대로 유지
4. 자격증명발급대장 화면에 [새로고침] / [대장 정리] 버튼 추가
5. [대장 정리] 버튼을 눌렀을 때만 과거 누락 보정 및 번호원장 대조 실행

데이터 안전
- 이번 수정은 데이터 삭제/초기화 기능을 추가하지 않음
- DROP / TRUNCATE 추가 없음
- 기존 회원/미수금/수납 로직 변경 없음
- 기존 Railway 기동 안정화 및 미수금 속도 개선 수정 유지
