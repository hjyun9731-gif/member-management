수납/미수금 통합 완료본

[적용 방식]
- 기존 회원관리 기능/라우터/CRUD/모델 로직은 수정하지 않았습니다.
- 기존 파일 중 변경된 것은 app/main.py(라우터 연결)와 app/static/index.html(상단 메뉴 추가) 2개뿐입니다.
- 기존 파일 삭제 없음.
- 수납/미수금은 기존 license_holders.id를 회원 고유 ID로 그대로 사용합니다.

[화면]
- 전체 회원관리 상단 메뉴에 "수납/미수금" 추가
- 클릭 시 /receivables 진입
- 수납처리 / 미수금현황 / 폐업 미수금 / 연락관리

[연동 규칙]
- 전체회원관리 신규등록 → 미수금에서 자동 인식
- 가입 회원 → 협회비 10,000원/대
- 미가입 회원 → 관리비 5,000원/대
- 신규등록일이 2026-09-01 / 09-15 / 09-30 모두 첫 부과일은 2026-10-01
- 폐업/양도/이관 회원 → 활성목록 제외, 이후 부과 종료, 기존 미수금은 폐업 미수금에서 보존/수납 가능
- 연락상태: 미연락 / 연락완료 / 부재 / 재연락 필요 / 문자발송
- 연락일/방법/상태/담당자/메모 이력 저장

[기존 장부 데이터]
- 2026 원본 3,239명
- 월별 레코드 38,868건(1~12월 구조)
- 원본 현재 미수금 합계 335,675,000원
