2. 2027-01부터
   - 비택배 일반 관리비 자동부과 시작
   - 기존 자격증명발급일 기준 첫 부과 계산을 유지하되 2027-01보다 앞서지 않음
3. 배포 시 기존 DB에 잘못 생성된 2026년 비택배 일반 관리비 source='auto' 행만 1회 제거
   - 2026 legacy 잔액/월별장부, 실제 입금, 수동조정은 건드리지 않음
