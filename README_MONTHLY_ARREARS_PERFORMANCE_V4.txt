member-management 미수금 월별 성과 대시보드 V4
기준일: 2026-08-31

[사용자 요구 반영]
1. 기존 미수금 대시보드의 지역별/계정별/연락률/고액미수 중심 화면 제거
2. 미수금이 '몇 년 몇 월 대비 얼마나 줄고/늘었는지'를 최우선으로 표시
3. 기준월 / 비교월을 직접 선택해 월말 미수금 비교
4. 비교기간 실제 수납액 / 부과액 / 수납·부과율 표시
5. 회원별 미수 감소액 / 증가액 및 감소·증가 회원수 표시
6. 미수회원 증감 / 완납 전환 / 신규 미수 / 미수 감소 실적 표시
7. 월말 총 미수금 추이 표시
8. 월별 부과액 vs 수납액 비교 표시
9. 월별 수납/부과율 표시
10. 월별 성과표 제공
    - 전월말 미수
    - 당월 부과
    - 당월 수납
    - 수납/부과율
    - 월말 미수
    - 전월 대비 증감액
    - 증감률
    - 미수회원
    - 완납전환
    - 신규미수
11. 연락현황은 미수금 대시보드에서 완전히 제거
12. 연락관리 탭은 기존대로 실제 연락기록이 있는 회원만 표시
13. Excel 다운로드 연한 노란색 유지
14. 상단/하위 메뉴 Bold 유지
15. 양도양수대장 가운데정렬/화살표 제거/관리버튼 잘림 수정 유지

[비교 기준]
- 기준월과 비교월은 '월말 잔액'끼리 비교합니다.
- 예: 2026년 7월 → 2026년 8월 선택 시 7월말 미수와 8월말 미수를 비교하고,
  그 사이의 8월 부과액/수납액을 성과로 표시합니다.
- 장기간 비교(예: 2026년 1월 → 2026년 8월)는 1월말에서 8월말까지의 변동과
  2~8월 기간 부과/수납 합계를 표시합니다.
- '수납/부과율'은 실제 수납액 ÷ 해당 기간 부과액입니다.
  100%를 넘으면 당월 부과뿐 아니라 과거 미수까지 추가 회수했다는 의미입니다.
