최종 UI 통합 패치 — 2026-08-31

이번 패치는 화면표시만 정리합니다. DB/API/저장/등록/수정/삭제 로직은 변경하지 않습니다.

[인허가/변경]
1) 양도양수대장
- 신규등록대장과 동일한 정보 밀도/색상/링크/배지 스타일
- 양수자를 본문 핵심으로 표시
- 양도자는 기본 접힘, 행별 ▸ 버튼으로 펼침/닫기
- 상단 '양도자 전체보기 / 전체닫기'
- 양수자 가입/미가입 표시
- 양도자 가입/미가입/미확인 표시
- 가입일자는 실제 가입자만 표시
- 도내양도 관련 색상은 진한 초록이 아니라 연한 연두색 톤

2) 폐업현황
- 신규등록대장과 같은 표 스타일
- 기존관리번호 + 폐업관리번호 동시 표시
- 가입 / 미가입 표시
- 가입자만 실제 가입일자 표시
- 핸드폰/차종/유종/주소/비고까지 한 화면에서 확인

[수납/미수금]
3) 폐업관리
- '처리정보' 컬럼 제거
- 관리번호 + 구분 자체로 처리 유형 확인
- 현재 폐업자: 관리번호/구분/회원/지역/차량번호/핸드폰/잔액
- 전체 폐업이력은 위 항목 + 현재상태

4) 수납처리/미수금현황 구분 유지
- 수납처리: 실제 입금 업무
- 미수금현황: 미수금 조회/분석
- 기존 클릭/상세/입금/연락 기능 유지

[전체 시스템 표]
5) 표 가운데 정렬
- 신규등록대장 / 양도양수대장 / 폐업현황 / 변경이력대장
- 수납처리 / 미수금현황 / 폐업관리 / 연락관리 / 월별장부
- 기타 시스템의 table th/td
- 전화번호/U+문자/관리버튼/금액까지 가운데 정렬

수정 파일:
- app/static/app.js

- app/static/receivables.css

- 회원 클릭/상세 조회
- 입금 저장
- 양도양수/폐업 업무 처리 로직
