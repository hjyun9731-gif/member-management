[최종 운영 구조]
- 최신 2026 미수금 파일 3,238명 스냅샷은 기준원장 1회 이관용.
- 그 이후 PostgreSQL DB가 공식 원장이다. 미수금 엑셀을 주기적으로 다시 올릴 필요가 없다.
- 프로그램에서 입력한 수납/선납/연락은 기준원장 갱신 시 삭제하지 않는다.

[회원 자동연동]
- 전체회원관리에서 신규등록 완료 즉시 수납/미수금에 표시.
- 신규회원은 등록월 0원 + '부과대기'.
- 첫 부과일은 신규등록월 다음 달 1일.
- 기존 2026 원장 회원은 신규 부과대기로 오판정하지 않는다.
- 가입일자 유효: 협회비 / 가입일자 없음: 관리비.
- 기존 70세 및 수동계정은 그대로 보존.

[월 자동부과]
- 협회비: 월 10,000원
- 관리비: 월 5,000원
- 70세: 월 5,000원
- Railway 서비스 내부 백그라운드 스케줄러가 15분마다 월 변경만 확인.
- 실제 전수 월부과는 월 1회만 실행.
- 직원이 수납화면을 열지 않아도 새 달 부과 가능.
- 동일 회원/동일 월 UNIQUE + 월 marker로 이중부과 차단.
- 폐업회원은 폐업 이후 신규부과 중단.
- 과거 charge의 계정 타입은 나중에 가입상태가 바뀌어도 소급변경하지 않는다.

[미수/선납]
- 잔액 > 0: 미수
- 잔액 = 0: 완납
- 잔액 < 0: 선납금
- 선납은 다음 달 부과와 자동 상계되고 남은 금액은 계속 선납으로 이월.
- 최신 기준원장: 미수 2,681명 / 328,928,000원, 선납 185명 / 4,738,000원, 완납 372명.

[수납]
- 개별 수납등록 유지: 현금/누락/특수건 등 예외처리용.
- 통장/결제내역 일괄수납 추가: xlsx/xls/xlsm/csv.
- 자동 컬럼탐지: 입금일/결제일, 입금액/결제금액, 입금자명/적요, 차량번호, 관리번호, 핸드폰, 거래/승인번호 등.
- 자동매칭 우선순위: 기존 입금자 매칭이력 -> 관리번호 정확일치 -> 차량번호 정확일치 -> 핸드폰 정확일치 -> 성명 유일일치.
- 애매한 동명이인/미매칭은 자동반영하지 않고 '확인필요'로 남김.
- 확인필요 거래는 회원검색 후 수동연결 가능.
- 한 번 수동확정 후 반영한 입금자명은 다음 업로드 때 자동매칭 학습.
- 같은 거래 재업로드 및 파일 내부 중복은 fingerprint로 중복제외.
- 자동/수동 매칭된 건만 '일괄 반영'. 확인필요/중복은 반영하지 않음.

[폐업/양도/이관]
- 수납화면에서 회원업무 버튼으로 기존 전체회원관리의 폐업 API를 그대로 호출.
- 새로운 별도 폐업 로직을 만들지 않는다.
- 현재 status=active 회원은 과거 폐업이력이 있어도 현재 폐업자로 오판정하지 않는다.
- 폐업관리 기본: 현재 실제 폐업자만.
- 전체 폐업이력: 기존 폐업/양도/이관 전체 이력 별도 조회.
- 폐업관리번호/구분/접수일/처리일/양수인/이관·양도지역/사유 표시.
- 폐업해도 기존 미수/선납/입금/연락 이력 보존.
- 폐업회원도 남은 미수금 수납 가능.
- 폐업 미수금 연결은 현재 member_id를 최우선으로 사용하고 과거 이력은 성명+차량 등 엄격매칭. 차량번호만으로 다른 사람 금액을 붙이지 않는다.

[연락관리]
- 수납처리 목록에는 불필요한 연락 컬럼을 제외.
- 미수금현황/연락관리/회원상세에서 연락상태와 이력을 관리.
- 연락일/방법/상태/담당자/메모 누적 저장. 기존 기록 덮어쓰기 금지.
- 폐업 전 저장한 연락도 폐업 후 그대로 유지.

[엑셀 다운로드]
- 현재 화면에 걸린 검색/지역/계정/부과상태/연락상태/폐업범위 필터를 그대로 적용.
- 현재 페이지 50건이 아니라 필터에 해당하는 전체 결과 다운로드.
- 주소, 핸드폰번호, 전화번호 포함.
- 미수금/선납금/현재잔액/회원상태/연락상태/회원관리번호/폐업관리번호/폐업·양도·이관 정보 포함.
- 다운로드한 Excel 자체에도 자동필터 적용.

[성능]
- 회원 목록 50명 서버 페이지네이션.
- 검색은 DB에서 LIMIT/OFFSET 처리.
- 회원 상세는 선택한 회원 데이터만 조회.
- 목록/요약 API마다 3천명 전체 sync를 하지 않는다.
- 백그라운드도 15분마다 신규 프로필 없는 회원만 제한 조회하고, 전수 월부과는 월 1회.
- 신규회원 즉시노출과 월부과 안정성을 유지하면서 기존 전체회원관리 속도에 영향을 최소화.

[UI]
- 화이트 + 저채도 파스텔.
- PC 1440~1920 기준.
- KPI 6개 한 줄, 패딩/공간낭비 축소.
- 좌측 목록 + 우측 상세를 한 화면에 유지.
- 가로스크롤 최소화, 좌우 패널 상단 정렬.
- 폐업관리도 목록+상세 구조 유지.
- '통장/결제 일괄수납' 버튼을 상단에 배치.
