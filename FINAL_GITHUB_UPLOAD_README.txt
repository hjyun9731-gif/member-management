[수납/미수금 운영]
- 최신 2026 기준원장은 최초 1회 이관용.
- 이후 PostgreSQL DB가 수납/미수금 운영원장.
- 프로그램 수납/선납/연락 이력은 재기동/기준원장 확인 때 삭제하지 않는다.

[신규회원 / 첫 부과일]
- 신규회원은 전체회원관리 등록 즉시 수납/미수금에 표시.
- 기존 원장 회원은 부과대기로 오판정하지 않는다.
- 협회비: 가입일자(membership_date)의 다음 달 1일이 첫 부과일.
- 관리비: 자격증명발급일자(certificate_issue_date)의 다음 달 1일이 첫 부과일.
- 해당 기준일이 없으면 첫 부과일 화면은 0, 자동부과 없음.
- created_at/인가일자는 첫 부과일 대체값으로 사용하지 않는다.
- 월 금액: 협회비 10,000원 / 관리비 5,000원 / 70세 5,000원.
- 동일 회원/동일 월 중복부과 금지.
- 폐업회원은 이후 신규부과 중단.

[미수 / 선납]
- 잔액 > 0: 미수
- 잔액 = 0: 완납
- 잔액 < 0: 선납
- 선납은 다음 달 부과에 자동 상계 후 남은 선납 계속 이월.
- 개별 입금/선입금/연락 이력 보존.

[수납]
- 개별수납 유지.
- 통장/결제내역 일괄수납 지원: xlsx/xls/xlsm/csv.
- 자동매칭: 기존입금자 이력 -> 관리번호 -> 차량번호 -> 핸드폰 -> 성명 유일일치.
- 애매한 건 확인필요, 중복거래 제외, 확인된 건만 일괄반영.

[폐업]
- 현재 실제 폐업자와 전체 폐업이력 분리.
- 현역회원은 과거 폐업이력이 있어도 현재 폐업으로 판정하지 않음.
- 기존관리번호와 폐-/양-/이- 폐업관리번호 별도 표시.
- 폐업 후에도 기존 미수/선납/입금/연락 이력 유지, 추가 수납 가능.
- 차량번호 하나만으로 과거 미수금 강제연결하지 않음.

[연락처 / 주소 / 문자]
- 수납/미수금 목록과 상세에서 기존 관리번호, 핸드폰번호, 주소 표시.
- U+ 문자 버튼 추가.
- 발송닷컴 API를 새로 호출하지 않음.
- 직원 PC의 LG U+ CRM Pro Web과 로컬 Bridge로 수신번호/문구 전달.
- 실제 전송 성공 응답이면 연락이력에 문자발송 자동 저장.
- U+ 외부제어가 안 되는 PC에서는 번호·내용 복사 기능 제공.

[엑셀 다운로드]
- 현재 검색/지역/계정/부과상태/연락/폐업범위 필터 그대로 전체 결과 다운로드.
