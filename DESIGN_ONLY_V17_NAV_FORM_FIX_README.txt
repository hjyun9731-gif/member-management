V17 적용 내용
- 대시보드 하단 버튼을 실제 동작하도록 수정
  · 회원 대시보드 → 보고/집계 → 회원대시보드
  · 수납/미수금 관리 → /receivables 실제 링크
  · 기한관리 전체보기 → 상단 기한관리 메뉴
  · 최근 업무 전체 기록 보기 → 보고/집계 내 이력 탭 우선 탐색
- 예정자 입력폼을 12열 기준으로 재정렬
  · 기본정보 4개 동일 폭
  · 전화/핸드폰 짧게 + 주소 2배 폭
  · 자격증명 핵심 3개 동일 폭
  · 차종/유종 짧게
  · 사업정보: 사업자번호 3 / 소속업체 5 / 가입일자 4
